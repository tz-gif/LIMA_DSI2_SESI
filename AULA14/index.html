FLEBOX

O Flexbox é um modelo de layout unidimensional que permite distribuir espaço entre os itens de um contêiner e alinhar os itens de forma eficiente, mesmo quando seu tamanho é desconhecido ou dinâmico. Ele é especialmente útil para criar layouts responsivos e flexíveis flex-direction: define a direção principal do contêiner flexível, podendo ser em linha (row) ou em coluna (column). flex-wrap: controla se os itens flexíveis devem quebrar para a próxima linha ou permanecer em.
